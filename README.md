## 🚀 Features

* 📥 **All-in-One Downloader:** Download videos and audio from YouTube, Instagram, and Facebook with Cobalt API bypass.
* 🎵 **Audio Pro:** Voice-only output with noise and beat cancellation using FFmpeg.
* 🎨 **Sticker Maker:** Convert any image into a WhatsApp-ready sticker (In Development).
* 🔒 **Secure Cloud:** Encrypted storage for your files directly to a private GitHub repository.
* ⚡ **Real-time Status:** Check server ping and bot health instantly via Koyeb backend.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (WhatsApp Dark Mode UI), JavaScript.
* **Backend:** Node.js, Express.js.
* **API:** Cobalt.tools (for YouTube & Social Media Bypass).
* **Hosting:** - **Frontend:** GitHub Pages
    - **Backend:** Koyeb (Server)
* **Processing:** FFmpeg.
